## 📌 Overview

Welcome to the **Types of Computer Networks** section of my Networking & Cybersecurity Portfolio.

This section explores different types of computer networks based on their geographical coverage, size, architecture, and communication requirements.

It covers how networks are classified, how they connect devices across different distances, and where each network type is commonly used in real-world environments.

Understanding network types is essential for learning network infrastructure, network architecture, routing, switching, and network security.

---

## 🎯 Learning Objectives

Through this section, I aim to:

- Understand the different types of computer networks.
- Learn how networks are classified based on geographical coverage.
- Understand the characteristics of PAN, LAN, WLAN, CAN, MAN, WAN, and GAN.
- Identify the differences between various network types.
- Explore real-world applications of different networks.
- Understand the advantages and limitations of each network type.
- Build a foundation for advanced networking and cybersecurity.

## 🔐 Cybersecurity Relevance

Understanding different types of networks is important for developing networking and cybersecurity skills.

This knowledge helps develop the ability to:

- Understand network infrastructure and architecture.
- Identify network security requirements.
- Understand potential attack surfaces.
- Analyze communication across local and wide-area networks.
- Understand network segmentation and isolation.
- Identify security challenges in wireless and wired networks.
- Develop foundational knowledge for SOC operations.

These concepts support my preparation for an **Entry-Level SOC Analyst** position.
